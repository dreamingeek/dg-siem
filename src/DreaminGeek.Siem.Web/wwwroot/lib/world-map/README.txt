world.geo.json: country outlines for the dashboard world map.
Built from world-atlas 2.0.2 countries-110m.json (Natural Earth, public domain; packaging ISC, see LICENSE-world-atlas)
with ISO 3166-1 alpha-2 codes from i18n-iso-countries 7.14.0 (MIT, see LICENSE-i18n-iso-countries).
Each feature's "name" property is the alpha-2 code (e.g. "US"); "label" is the country name.
Antarctica (AQ) removed.
Rings crossing the antimeridian (Russia, Fiji) are shifted east so they draw without wrapping.
